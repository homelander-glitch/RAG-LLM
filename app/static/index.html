Privacy & Local Execution Verification

Technical guarantees that your documents, embeddings, and queries remain 100% on your machine.

✓
Documents Processed Locally

PDF, DOCX, and TXT parsing and chunking occur entirely on your local CPU. Files are saved in local storage.

✓
Embeddings Generated Locally

The all-MiniLM-L6-v2 SentenceTransformer model runs locally without connecting to HuggingFace or OpenAI cloud APIs.

✓
ChromaDB Vector Store Stored Locally

Vector indexes are persisted in the local directory (./chroma_db) on your hard drive.

✓
Local LLM Inference via Ollama

Language model inference runs on your machine via http://localhost:11434 with zero cloud API keys or telemetry.

✓
User-Level Document & Vector Isolation

Every document, vector embedding, and chat history is tagged with a unique user_id. Queries are strictly filtered so users cannot view or search other users' files.
